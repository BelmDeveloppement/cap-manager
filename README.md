# Le bon style

Jeu de plateau de management situationnel (plateau + dé) avec application téléphone : 72 situations, choix du style en secret, corrigé, pas à avancer, bilan de fin.

Ouvrir la page (GitHub Pages) : https://belmdeveloppement.github.io/cap-manager/

- Animateur : « Animateur : créer une partie », code à 4 caractères et QR code.
- Joueurs : scanner le QR code ou « Joueur : rejoindre », sans compte.
- Sans réseau pour tous : « Un seul écran ».

Les téléphones se connectent par WebRTC (PeerJS), sans serveur de jeu.
